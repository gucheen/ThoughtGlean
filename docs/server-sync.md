# 同步与数据管理

## 离线与跨设备

登录同一服务器即可同步多台设备。服务端保存完整数据，浏览器保留本机副本；首次使用需联网登录并加载数据，此后断网仍可记录、搜索和编辑。

登录、恢复联网、返回页面及每分钟会触发同步，也可在「设置 → 同步与运行状态」点击「立即同步」，查看待同步数量、最近成功时间和错误。

本机保存不代表已上传。清除浏览器数据或更换设备前，应确认同步完成；未提交的草稿只保存在当前浏览器。

## 冲突与删除

多设备同时修改同一记录时会保留冲突版本。在冲突提示中打开记录，选择「保留当前」「使用另一版本」或「合并后保存」。

删除的记录进入回收站，可从「设置 → 回收站」恢复。空间收起和归档不会删除记录；只要记录属于任意一个收起或归档的空间，就不出现在日常，仍可通过全部记录和星标查找。

## 备份与恢复

- **下载完整备份**：「设置 → 备份与导出」下载当前浏览器数据的 JSON 副本，包含图片；备份前先完成同步。
- **恢复备份**：在同一位置选择 JSON 文件。恢复会替换当前浏览器的记录和图片，并将恢复的数据加入同步队列；操作前先备份现有数据。
- **导出 Markdown**：导出可直接阅读的文本，完整恢复请使用 JSON 备份。
- **服务端自动备份**：独立保存为 ZIP，配置和校验方式见[部署与维护](deployment.md#自动备份与恢复演练)。网页恢复入口接受 JSON，不能直接导入 ZIP。
